🗺️ CORS Test - lvermgeo.rlp.de Höhenlinien Daten

📋 Test Übersicht

Dieses Script testet, ob die Höhenlinien-Daten von lvermgeo.rlp.de durch CORS blockiert werden. Wenn CORS blockiert ist, brauchst du einen Backend-Proxy (wie den Server.js).

Test 1: Direkter Zugriff auf lvermgeo.rlp.de (Browser-seitig)

Versucht direkt auf die WMS-Höhenlinien-Daten zuzugreifen (wird wahrscheinlich CORS-blockiert)

Test 2: Zugriff über localhost:3000 Proxy (falls Server läuft)

Versucht über den Node.js Backend-Server auf die Daten zuzugreifen (sollte funktionieren)

Test 3: CORS Preflight Check

Überprüft die CORS-Header der lvermgeo.rlp.de Domain

Test 4: Höhenlinien auf Leaflet-Karte laden

Versucht, die Höhenlinien-Layer auf einer Leaflet-Karte zu laden (über Proxy)

📊 Zusammenfassung

Test Beschreibung CORS-Status Lösung
Test 1 Direkter Zugriff Nicht getestet Backend-Proxy notwendig, wenn blockiert
Test 2 Über Proxy (localhost:3000) Nicht getestet Funktioniert nur, wenn Server läuft
Test 3 CORS Headers Check Nicht getestet Zeigt verfügbare CORS-Headers

💡 Empfehlungen

  • Wenn Test 1 fehlschlägt: Du brauchst einen Backend-Proxy (Server.js oder Vercel)
  • Wenn Test 2 erfolgreich ist: Der lokale Proxy funktioniert - deploye ihn auf Vercel
  • Wenn Test 3 zeigt "CORS blockiert": Verwende definitiv einen Proxy
  • Nächster Schritt: Höhenlinien-Daten in app.js über Proxy laden
